## Temuan Lintas Modul (Cross-Cutting & Architectural Violations)

Pemeriksaan terhadap codebase skci-teratai menemukan beberapa pelanggaran standar arsitektur dan kebutuhan lintas modul yang perlu ditindaklanjuti:

### 1. Data Sensitif & Keamanan Akun (NFR-SEC-01 / CC-04 / CC-05)
- **Penyimpanan Password Default dalam Bentuk Plaintext:**
  - Lokasi: `services/identity/migrations/0001_init.up.sql:70`, `services/identity/internal/handler/users.go:29-35`.
  - Temuan: Kolom `default_password` disimpan dalam plaintext di tabel `users` dan dikembalikan ke API response list/get sebelum pengguna mengganti password.
- **Bocoran Password Default pada Ekspor CSV:**
  - Lokasi: `services/identity/internal/handler/users.go:712` (`ExportUsersCSV`).
  - Temuan: Handler ekspor CSV menuliskan password default langsung ke dalam file unduhan (`cw.Write([]string{nisn, u.Name, u.Email, password, tokensByUser[u.ID]})`).
- **Ketiadaan Manajemen Sesi & Log Keamanan (CC-05 / FR-05-004 / FR-06-002):**
  - Lokasi: `services/identity/internal/handler/auth.go`.
  - Temuan: Identity sepenuhnya menggunakan stateless JWT tanpa penyimpanan session aktif, revocations blacklist, riwayat login, maupun log audit kejadian keamanan (login berhasil/gagal, akun terkunci).

### 2. Aturan Finansial & Standar Mata Uang (BR-FIN-04 / BR-FIN-06 / GEMINI.md §4)
- **Belum Ada Mekanisme Saldo Deposit (BR-FIN-04):**
  - Lokasi: `services/billing/internal/model/domain.go:106` (`Outstanding`).
  - Temuan: Fungsi `Outstanding` memotong overpayment ke 0 (`if net < 0 { return 0, nil }`), namun kelebihan bayar tidak disimpan ke entitas deposit siswa dan tidak dialokasikan otomatis ke tagihan berikutnya.
- **Ketiadaan Mapping COA per Komponen Biaya (BR-FIN-06):**
  - Lokasi: `services/billing/migrations/0001_billing.up.sql:10`, `services/billing/internal/handler/bills.go`.
  - Temuan: Skema `billing_schemes` dan `billing_scheme_items` tidak memiliki relasi atau validasi ke akun COA (pendapatan dan piutang). Tagihan dapat diterbitkan tanpa mapping akuntansi.
- **Ketiadaan Auto-Posting Jurnal dari Billing ke Accounting (BR-ACC-05 / BR-ACC-06):**
  - Lokasi: `services/billing/internal/handler/bills.go`, `services/billing/internal/handler/payments.go`.
  - Temuan: Service billing dan Laravel accounting beroperasi sepenuhnya terisolasi tanpa HTTP client internal atau event bus untuk sinkronisasi jurnal harian.

### 3. Integritas Audit Trail & Maker-Checker (CC-03 / NFR-AUD-01 / BR-GEN-09)
- **Audit Trail Terfragmentasi & Parsial:**
  - Lokasi: `services/admission/migrations/0001_admission.up.sql:57`, `services/billing/migrations/0001_billing.up.sql:98`.
  - Temuan: Tabel `audit_events` hanya ada di admission dan billing. Service `identity`, `academic`, `attendance`, `exam`, `evaluation`, dan `report` tidak memiliki pencatatan perubahan data (before/after JSON). Belum ada pusat pencatatan audit log terpusat (sedang diatasi di T1).
- **Workflow Persetujuan (Approval) Masih Lokal:**
  - Lokasi: `services/attendance/internal/handler/leave.go`, `services/billing/internal/handler/refunds.go`.
  - Temuan: Approval dilakukan langsung di handler masing-masing service dengan model kolom lokal (`decided_by`), belum terhubung ke antarmuka terpadu Approval Center (sedang diatasi di T1).

### 4. Hardcode Nilai Bisnis & Batasan File (BR-GEN-08)
- **Limit Ukuran Upload File Ter-hardcode:**
  - Lokasi: `services/attendance/internal/handler/leave.go:23` (`leaveMaxAttachment = 2 << 20 // 2 MB`), `services/report/internal/handler/report_template.go:45` (`10 << 20 // 10MB`).
  - Temuan: Batasan ukuran lampiran ter-hardcode sebagai konstanta Go di beberapa handler, bukan parameter konfigurasi dinamis.
