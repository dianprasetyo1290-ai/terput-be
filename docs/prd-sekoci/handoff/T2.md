## 1. Ringkasan Implementasi

T2 mengimplementasikan modul lengkap **Human Resource Information System (HRIS)** dan **Employee Self-Service (ESS)** untuk Teratai Putih Global School.
- **Backend (`services/hr`):** Go microservice (chi v5 + pgx v5) di port 8092 dengan enkripsi AES-GCM-256 + HMAC-SHA256 blind indexing untuk data sensitif (NIK, NPWP, Telepon, Rekening, Gaji Pokok, Alamat) (NFR-HR-01). Memiliki pure logic functions yang diuji tabel, storage berkas privat lokal, background jobs berbasis PostgreSQL advisory lock, dan integrasi maker-checker Core Approval Center (POST `/internal/approvals`).
- **Identity (`services/identity`):** Migrasi `0015_hris_users.up.sql` memperlebar role check constraint untuk mendukung `hr_admin`, `hr_manager`, `payroll_officer`, `pegawai`. Endpoint internal `/internal/users/employees` untuk sinkronisasi akun.
- **Frontend (`web/`):** 11 view Vue 3 TypeScript lengkap untuk portal SDM dan portal Pegawai (ESS), didukung store `useEmployeeStore`, Tailwind v4 styling, komponen UI shadcn, dan format currency IDR serta tanggal Asia/Jakarta.
