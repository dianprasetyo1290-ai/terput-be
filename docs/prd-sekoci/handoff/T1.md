# Handoff Task T1: Service `core` — Approval Center, Integration Exception Queue, Central Audit Trail, New Roles & Auto Journal

## 1. Ringkasan & Daftar File

Task T1 mengimplementasikan service `core` (port 8091) sebagai fondasi arsitektur SEKOCI LMS yang menyediakan:
1. **Approval Center** (Menu 79): Konfigurasi alur bertingkat, penentuan tahap otomatis berbasis nominal (`min_amount_idr`) dan flag kondisi (`condition_flag`), inbox persetujuan terpusat, maker-checker enforcement (BR-GEN-09), delegasi wewenang berbatas waktu, eskalasi otomatis berbasis SLA, serta callback asinkron idempoten ke service pemanggil.
2. **Integration Exception Queue** (Menu 80): Antrean penanganan galat webhook, posting jurnal, dan notifikasi; retry otomatis dan manual ber-idempotency key; penugasan penyelesaian; penyamaran data sensitif secara berlapis (defense in depth).
3. **Audit Trail Pusat** (Menu 06): Pencatatan terpusat event mutasi dan keamanan (login sukses/gagal, perubahan peran) dengan sanitasi field PII/sensitif mentah, diff JSON before/after, serta ekspor CSV berizin.
4. **Perluasan Peran HR & Finansial**: Migrasi role baru di identity (`hr_admin`, `hr_manager`, `payroll_officer`, `recruiter`, `training_admin`, `auditor`, `finance_manager`, `pegawai`) beserta proteksi rollback aman.
5. **Auto Journal Endpoint (Laravel Accounting)**: Pintu masuk jurnal otomatis idempoten bagi payroll dan payment gateway dengan verifikasi konsistensi debet-kredit dalam integer rupiah dan proteksi `X-Internal-Key`.

### Sumber Porting & Rujukan Pola
- **Layout Service Go**: `services/billing/` (`cmd/server/main.go`, `internal/{common,config,handler,store,model,client}`).
- **Pola Auth & Helper HTTP**: `services/billing/internal/common/` (`auth.go`, `response.go`, `http.go`, `internal.go`, `sentry.go`).
- **Migrasi Database**: `services/admission/migrations/` (golang-migrate, sequence berurutan, up/down terbalik).
- **Audit & Idempotensi**: Pola `audit_events` and `UNIQUE(school_id, idempotency_key)` dari `services/admission/`.
- **Accounting Trans No & Tenancy**: Pola `PriorYearAdjustmentService` dan `SsoController` di `services/accounting`.

## 5. Penyimpangan dari Spesifikasi, Asumsi, dan Catatan Integrasi

1. **Uji Playwright (End-to-End)**: Sesuai aturan **Mode Paralel (§7b)** di `GEMINI.md`, dev server dan browser testing lokal di port tetap dilarang untuk mencegah bentrok port antar agen. Uji Playwright end-to-end multi-peran dijadwalkan berjalan pada gelombang integrasi pasca-merge per runbook `docs/prd-sekoci/PARALLEL.md`. Seluruh skenario alur (maker-checker, nominal steps, reject comment, retry exception) telah diverifikasi tuntas melalui table test dan HTTP handler test suite.
2. **Ketergantungan ke Service HR (`subject_user_id` / direct_supervisor)**: Saat mengevaluasi tahap `direct_supervisor`, service `core` memanggil `GET {HR_URL}/internal/employees/by-user/{subject_user_id}/supervisor`. Jika URL HR belum dikonfigurasi / mengembalikan 404, request pembuatan approval mengembalikan 422 dengan pesan informatif `"service HR belum aktif untuk resolusi atasan langsung"`, sesuai spesifikasi T1 §4.2.
3. **Komponen Reusable `ApprovalTimeline.vue`**: Disediakan di `web/src/components/core/ApprovalTimeline.vue` menerima props `sourceService` dan `sourceId`. Komponen ini siap dipakai langsung oleh task T2–T7 pada detail pengajuan cuti, lembur, perubahan gaji, pengadaan, dan permohonan pengembalian dana.
