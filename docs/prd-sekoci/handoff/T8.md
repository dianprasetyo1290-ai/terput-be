# Handoff T8: Audit Gap FR Menu 01–77 (PRD Bagian 1 v1.0)

## 1. Ringkasan
- **Task:** T8 — Audit gap FR menu 01–77 (laporan saja, TANPA mengubah kode).
- **Branch:** `feat/T8-audit`.
- **Deskripsi:** Melakukan audit menyeluruh terhadap 77 menu (Grup 1 hingga Grup 10) pada dokumen `Master_PRD_SaaS_SEKOCI_Bagian1_v1.0.md` terhadap kode nyata di skci-teratai. Setiap Kebutuhan Fungsional (FR) dan Kriteria Penerimaan (AC) diperiksa ketersediaan end-to-end-nya (skema DB/migrasi, API endpoint/handler, UI router & view frontend, penegakan aturan bisnis di server, serta unit test terkait).
- **Hasil Utama:**
  - Laporan audit lengkap tersusun di `docs/prd-sekoci/audit/01-77.md` (1.048 baris).
  - Total 207 FR dievaluasi: **135 Ada (65.2%)**, **32 Sebagian (15.5%)**, **31 Belum (15.0%)**, dan **9 Di luar scope (4.3%)**.
  - Total 110 AC dievaluasi: **24 memiliki automated test (21.8%)**, **86 belum memiliki automated test (78.2%)**.
  - 4 kategori temuan pelanggaran lintas modul berhasil diidentifikasi (keamanan password plaintext, deposit & mapping COA, fragmentasi audit trail, hardcoded upload limits).
  - 14 usulan task lanjutan (T9 hingga T22) berhasil dipetakan per service dengan prioritas MoSCoW dan estimasi ukuran (S/M/L).

## 7. Penyimpangan dari Spec, Asumsi & Pertanyaan Terbuka

1. **Menu 64 (Student Settings) dan Menu 77 (Teacher Settings):**
   Pada teks PRD Bagian 1, kedua menu ini secara eksplisit diberi catatan: *"Tidak ada kebutuhan spesifik; seluruh kebutuhan menu ini tercakup oleh CC-05 dan CC-08."* Karena itu, kedua menu ini dihitung 0 baris FR/AC spesifik tersendiri, namun dinilai status implementasinya melalui kebutuhan lintas modul CC-05 dan CC-08.
2. **Keterkaitan dengan Task Lain yang Sedang Berjalan (Gelombang 1):**
   - Sebagian besar status "Belum" dan "Sebagian" pada Grup 4 (Payment, Menu 26–31) merupakan ruang lingkup langsung dari task **T6** (Payment Gateway).
   - Ketiadaan pencatatan audit log terpusat dan Approval Center pada Menu 06, Menu 41, Menu 42, dan Menu 79 merupakan ruang lingkup langsung dari task **T1** (Core Approval & Audit).
3. **Penyimpanan Password Plaintext:**
   Temuan bahwa `users.default_password` disimpan dalam plaintext dan diekspor ke CSV pada `services/identity/internal/handler/users.go` ditandai sebagai temuan keamanan berprioritas tinggi (NFR-SEC-01) yang direkomendasikan untuk segera diperbaiki pada task T9.
